## ⚠️ 03. 迷航避坑：四大虚假宣传防触礁指南

1. **辨别“口头专线”陷阱**：
   - 很多小作坊将普通公网中转宣传为内网 IPLC。实测只需运行 MTR 路由追踪，公网中转会经过公网骨干路由跳数，且在晚高峰丢包率通常飙升至 10% 以上。
2. **警惕“无限流量”与低价年付**：
   - 国际优质带宽成本高昂，宣称“几十元年付且不限流量”的服务通常采用超售几百倍策略，极易因资金链断裂而跑路。
3. **避免 DNS 伪装与双向污染**：
   - 客户端未配置正确的分流分流规则会导致国内流量绕行海外，不仅速度极慢，还会造成域名解析污染。
