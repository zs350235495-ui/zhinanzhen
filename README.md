## 🌐 国际海缆物理拓扑与光纤传输时延极限模型

跨国网络延迟并非软件优化能够随意突破，其理论下限直接由光纤介质传播速度与物理敷设路径决定：

### 1. 光纤传输速率与理论往返时延（RTT）
光在石英玻璃光纤中的折射率约为 $n \approx 1.4682$，光在介质中的传播速度为：
$$v = \frac{c}{n} \approx \frac{299,792\text{ km/s}}{1.4682} \approx 204,190\text{ km/s}$$
因此，纯光纤物理单向延迟约为 **$4.9\text{ ms} / 1,000\text{ km}$**，往返理论最低时延极限约为 **$9.8\text{ ms} / 1,000\text{ km}$**。

### 2. 亚太核心海缆路由实测参考值
* **沪日链路（上海 - 东京）**：物理光缆直线与海缆走线距离约为 2,200 km - 2,800 km，加上终端光放大器（EDFA）与 DWDM 设备编解码，物理光纤最低 RTT 极限在 **24ms - 28ms** 之间。
* **穗港链路（广州 - 香港）**：陆缆物理距离约 150 km - 180 km，理论最低传输 RTT 在 **4ms - 6ms** 之间。
* **跨太平洋链路（上海 - 洛杉矶）**：经由跨太平洋海缆（如 NCP/FASTER），物理路由超过 10,500 km，端到端光纤传输极限 RTT 约为 **120ms - 135ms**。

凡宣传大幅低于上述物理极限的数值，均为测试节点位置偏移或 ICMP 伪造响应。

## 🔬 骨干网 QoS 调度与队列拥塞算法 (Queue Management)

晚高峰期间网络质量劣化，核心在于中间路由器缓冲膨胀（Bufferbloat）与 QoS 丢包策略：

### 1. 主动队列管理 (AQM: CoDel vs RED)
* **Tail Drop（尾部丢弃）**：传统队列填满后直接丢弃后续所有数据包，引发全局 TCP 慢启动同步，导致吞吐断崖式下跌。
* **CoDel (Controlled Delay)**：通过监控数据包在队列内的驻留时间，主动在缓冲区过载前温和标记/丢弃高延迟包，确保队列保持浅层低延迟状态。

### 2. 国际专线与公网路由的抗拥塞对比
* **IPLC/IEPL 国际专线**：运营商提供硬管道带宽隔离保证，无需经历公网自治系统之间的 BGP 动态抖动与国际出口队列竞争，因此即使在晚高峰依然能维持 < 0.1% 的极低丢包。
* **公网 BGP 直连**：晚高峰时段由于海缆带宽过载，公网出口设备强制触发 QoS 限速，TCP 窗口被频繁压缩，产生严重抖动与重传。
