Troubleshooting FAQ

常见配置排查与网络问答

总结了用户在安装配置 Clash、Sing-box、V2rayN 等代理软件时遇到的最常见 8 大高频报错与解决建议。

Q1. 打开软件提示 `Port 7890 is in use` 端口被占用怎么办？

这说明您电脑后台已有其他代理客户端（如老版本 Clash 或 V2rayN）占用了 7890 混合端口。解决方案：1. 彻底退出后台其他软件；2. 或在软件设置中将混合端口（Mixed Port）改为 7897 或 10809。

Q2. 开启代理后，为什么 Telegram / Discord 依然提示“连接中”？

Telegram 使用自定义 TCP/UDP 协议，若仅开启系统代理，Telegram 可能无法感知系统 HTTP 代理设置。请在软件中开启 TUN 模式，或者在 Telegram 设置 -> 高级 -> 代理类型中手动填写 `127.0.0.1:7890` SOCKS5 代理。

Q3. TUN 模式安装虚拟网卡失败，提示 Service Install Failed 怎么解决？

Windows 环境下通常因为安全软件拦截了驱动注入。排查办法：1. 暂时关闭 360 / 电脑管家；2. 右键选择“以管理员身份运行”软件；3. 在软件设置中手动点击“Manage Service -> Install”。

Q4. 访问国内网站（如百度、淘宝）速度变慢或提示异地登录？

这说明您的代理软件误将国内流量路由到了国外节点。请将软件模式设置为 Rule (规则分流) 模式，切勿设置为 Global (全局模式)。在 Rule 模式下，国内流量会保持 Direct 原生直连。

Q5. 机场节点提示 `TLS Certificate Failed` 或 SSL 握手超时？

请首先核对您操作系统的本地系统时间与北京时间是否精确同步。由于 TLS/QUIC 协议强校验时间戳，如果系统时钟偏差超过 60 秒，就会引发 SSL 证书报错。
