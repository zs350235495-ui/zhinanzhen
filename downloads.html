Windows 平台安装指南

推荐客户端：Clash Verge Rev / V2rayN 7.0

  1. 在下方列表点击下载 .exe 或 .msi 安装包。
  2. 若触发 Windows SmartScreen 保护，点击“更多信息” → “仍要运行”。
  3. 打开客户端，找到“订阅配置”页面，粘贴在 环球梯 或 大佬云 购买获得的订阅链接。
  4. 点击“一键导入/更新节点”，勾选开启“系统代理 (System Proxy)”或开启“TUN 虚拟网卡模式”。
🍎

macOS 平台安装指南

推荐客户端：Clash Verge Rev / Stash / Surge 5

  1. 苹果 Apple Silicon (M1/M2/M3/M4) 芯片选择 aarch64/arm64 安装包，Intel 芯片选择 x64 包。
  2. 双击打开 .dmg 映像文件，将软件图标拖入 Applications 文件夹。
  3. 首次打开若提示“无法验证开发者”，请进入“系统设置” → “隐私与安全性”，下滑点击“仍要打开”。
  4. 导入订阅后，在顶部状态栏开启系统代理即可流畅访问全网。

Android & 鸿蒙 HarmonyOS

推荐客户端：NekoBox for Android / Sing-box / Flclash

  1. 直接下载正版原生 .apk 安装文件，授权安装未知应用权限。
  2. 进入 NekoBox 或 Sing-box，点击右下角加号，选择“从剪贴板导入订阅链接”。
  3. 点击“分组节点测速”，选择延迟最低的香港或日本 IPLC 专线节点。
  4. 点击启动开关，同意系统提示的“建立 VPN 连接”弹窗，即可后台静默运行。

iOS / iPadOS 苹果手机指南

推荐客户端：Shadowrocket (小火箭) / Stash / Quantumult X

  1. 国区 App Store 暂不支持搜索，需在 App Store 登录非中国大陆地区 (如美区/港区) Apple ID。
  2. 在 App Store 搜索 Shadowrocket 或 Stash 完成安装。
  3. 使用手机 Safari 打开机场控制台，点击“一键导入小火箭”，或在小火箭内扫描二维码。
  4. 滑动顶部连接开关，首次使用输入 iPhone 锁屏密码允许添加 VPN 配置。

代理客户端防投毒与安全自查守则

近年来网络上频繁出现带有木马病毒、后门偷取浏览器 Cookie 的伪造代理软件（特别是搜索广告推广的假冒 Clash 官网）。请务必遵循以下防坑自查指南：

❌ 拒绝来源不清文件

切勿下载 Telegram 电报群分享的压缩包、未知论坛第三方修改版以及搜索引擎广告位置推荐的所谓的“破解版”。

✅ 认准 GitHub Release

本站所有下载按钮均直接定向指向开源社区权威 GitHub Repository 的 Release 版本发布列表，源码透明可查。

🔍 核对 SHA256 校验码

下载安装包后，可使用 PowerShell Get-FileHash 命令与 GitHub 仓库给出的 Hash 值对比，确保无篡改。

客户端下载与安装常见问题 FAQ

Q1 Windows 提示“Windows 已保护你的电脑 / SmartScreen 阻拦”怎么解决？

这是由于许多开源工具（如 Clash Verge Rev、Sing-box）没有购买昂贵的微软 EV 代码签名证书导致的正常安全提示。只要是从 GitHub 官方 Release 页面下载的 .exe，点击弹窗中的“更多信息”，再点击右下角的“仍要运行”即可正常安装。

Q2 macOS 提示“无法打开，因为无法验证开发者”或者“应用已损坏”怎么办？

这是 Mac 系统的 Gatekeeper 安全拦截机制。解决方法：

  1. 方法一：进入“系统设置” → “隐私与安全性”，找到底部被阻拦的应用，点击“仍要打开”。
  2. 方法二：打开终端 (Terminal)，输入命令：sudo xattr -rd com.apple.quarantine /Applications/Clash\ Verge.app 并输入开机密码回车即可。

Q3 没有外区 Apple ID，如何在 iPhone / iPad 上下载 Shadowrocket 小火箭？

因政策原因，Shadowrocket（小火箭）仅在非中国大陆区 App Store 上架（售价 $2.99）。您可以在苹果官网免费注册一个美区或港区 Apple ID，在 App Store 登录后通过充值卡兑换或绑定国际卡完成购买。切勿在系统设置中登录他人 iCloud 账户。

Q4 华为鸿蒙 HarmonyOS 4.0 及 HarmonyOS NEXT 对科学上网客户端支持如何？

HarmonyOS 4.0 及更早版本完全兼容标准 Android APK 文件，可直接安装 NekoBox 或 Sing-box。对于 HarmonyOS NEXT (纯血鸿蒙)，建议配合软路由全局加速，或使用跨平台纯 Web/Core 工具。

Q5 开启代理后发现提示“连通率正常但无法打开网页”或“端口被占用 9090”怎么处理？

这通常是由于系统代理设置残留或旧客户端未彻底关闭导致端口冲突。可在客户端设置中找到“重启内核”或“修改混合端口 (Mixed Port)”，将端口设为 7897 或开启 TUN 虚拟网卡接管模式。详见 新手配置教程。
