第一章：网络代理核心概念与名词释义

🔗

什么是“订阅链接 (Subscription URL)”？

订阅链接是机场服务商提供给您的一串包含密钥的专属网址（支持 Clash / Sing-box / Shadowrocket 格式）。

核心优势： 客户端填入链接后，每次点击“更新”，即可自动拉取最新的几十个底层节点。无需手动逐个复制节点配置。

🛡️

主流传输协议解析

节点协议决定了数据的加密与伪装手段：

  • VLESS / Reality： 极低延迟伪装 HTTPS 流量，抗封锁强。
  • Hysteria2 (歇斯底里): 基于 UDP/QUIC 协议，专治劣质宽带与高丢包。
  • Shadowsocks / Trojan： 经典稳定老牌协议。
⚡

专线 (IPLC/IEPL) vs 公网中转

线路架构直接决定网络连通品质：

  • IPLC/IEPL 内网专线： 走局域网点对点光缆，不经过公网墙，0 丢包。
  • BGP 入口中转： 优质公网入口，性价比高。
  • 公网直连： 无入口备份，极易因 IP 封锁失联。

Windows 平台配置教程（推荐 Clash Verge Rev）

适用系统：Windows 10 / Windows 11 (64位)

STEP 01

下载与安装

在 下载中心 获取 Clash Verge Rev 最新 .exe，双击运行完成安装。

STEP 02

复制机场订阅

登录在 环球梯 或 大佬云 购买的控制台，点击“一键复制 Clash 订阅”。

STEP 03

导入与更新

打开 Clash Verge 侧边栏“订阅 (Profiles)”，粘贴 URL 并点击“导入”，右键设为当前活动配置。

STEP 04

启动系统代理/TUN

在主页开启“系统代理 (System Proxy)”开关，或开启“TUN 模式”全流量接管，即可畅游全网。

🍎

macOS 苹果电脑配置教程（推荐 Clash Verge / Stash）

适用系统：macOS Ventura / Sonoma / Sequoia (M系列及Intel芯片)

STEP 01

拖拽安装应用

下载 `.dmg` 文件，将 Clash Verge 图标拖入 `Applications` 应用目录。

STEP 02

安全权限授权

若提示“无法验证开发者”，在“系统设置” → “隐私与安全性”中点击“仍要打开”。

STEP 03

导入机场订阅

复制机场面板订阅，粘贴导入并在“节点选择 (Proxies)”中选择节点。

STEP 04

开启网卡接管

点击顶部状态栏猫咪/网卡图标，勾选“设置系统代理”即可。

🤖

Android & 鸿蒙系统配置

  1. 下载 NekoBox 或 Sing-box 正版 APK 并安装。
  2. 在手机浏览器登录机场控制台，点击“复制订阅地址”。
  3. 打开 NekoBox 右上角加号，选择“从剪贴板导入”。
  4. 点击侧边栏“分组测速”，选择毫秒延迟 lowest 的节点，滑动启动开关并允许系统 VPN 连接。
📱

iOS / iPadOS (小火箭) 配置

  1. 在 App Store 登录非中国大陆地区 Apple ID，下载 Shadowrocket。
  2. 使用手机 Safari 打开机场控制台，点击“一键导入 Shadowrocket”。
  3. 小火箭自动弹窗解析节点列表，在“全局路由”处选择“配置 (Config)”防国内流量走代理。
  4. 滑动顶部“未连接”开关，输入 iPhone 锁屏密码允许添加 VPN 配置。

第三章：5 步故障快速诊断与排查流程图

STEP 1

排查订阅账户额度

登录机场控制台，核实账户是否到期、已用流量是否已跑满 100%。

排查率 40%
STEP 2

更新订阅与测试连通

右键点击“一键更新订阅”，剔除已被 GF-W 墙掉的死节点，选择绿色低延迟节点。

排查率 30%
STEP 3

开启 TUN 虚拟网卡模式

解决“延迟正常但打不开网页”或 UWP/命令行走代理失败，强行接管网卡级流量。

排查率 15%
STEP 4

排查混合端口冲突

若提示“Port 7890/9090 occupied”，在系统设置中将 Mixed Port 改为 7897 或 8889。

排查率 10%
STEP 5

重置系统代理与重启

关闭并重新开启客户端，或重启浏览器清除 DNS 缓存（chrome://net-internals/#dns）。

排查率 5%

第四章：规则分流 (Rule Set) 与 DNS 伪装进阶

🎯 智能分流规则 (GeoIP / Sub-Rule)

分流规则可以保障国内网站（如百度、淘宝、微信）直接直连走本地宽带，而国外网站（Google、YouTube、ChatGPT）自动绕过 GF-W 走代理节点。

Rule Direct: CN 域名 / 224.0.0.0/8 → 直连 (不消耗代理流量)

Rule Proxy: GFWList / Google / Netflix → 代理节点 (高速加密)

Rule Reject: 常见广告 / 追踪脚本 → 拦截拒绝

🌐 Fake-IP 模式与 DNS 防泄漏

传统 DNS 查询会将域名直接暴露给运营商从而遭到劫持污染。开启 Fake-IP 模式后，代理客户端先返回假 IP 给系统，再在远程节点完成真正 DNS 查询。

DoH (DNS over HTTPS): 加密 DNS 请求，防止 ISP 监控

Fake-IP 响应速度: 秒级建连，减少 200ms+ DNS 握手等待

DNS Leak Test: 可通过 dnsleaktest.com 验证隐私安全
